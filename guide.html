🌱 초급 · 제미나이로 수업용 시뮬레이션 만들기

준비물: 구글 계정약 30~40분결과물: 제미나이 공유 링크

코드는 몰라도 괜찮아요. 만들고 싶은 화면을 말로 설명하고, 나온 결과를 보면서 "여기를 이렇게 바꿔줘"라고 계속 다듬으면 됩니다.

  1. gemini.google.com에 구글 계정으로 로그인합니다.
  2. 입력창 아래 도구(＋)를 눌러 Canvas(캔버스)를 켭니다. 결과가 오른쪽 화면에 미리보기로 떠서 바로 눌러 볼 수 있어요.
  3. 프롬프트에 아래 네 가지를 넣고, 마지막에 "html로 만들어줘"를 붙입니다.
    ① 무엇을배울 개념
    ② 누구를대상 학년
    ③ 어떻게 조작슬라이더·버튼·입력
    ④ 무엇을 보여줄지그래프·애니메이션·숫자
  4. 예시 프롬프트를 복사해서 내 교과에 맞게 바꿔 보세요.
    중학교 2학년 수학 수업용으로 일차함수 그래프 탐구 도구를 만들어줘. 기울기와 y절편을 슬라이더로 바꾸면 좌표평면 위의 직선이 바로 움직이고, 식 y = ax + b도 함께 바뀌어 보였으면 좋겠어. html로 만들어줘.
    중학교 1학년 과학 수업용으로 물의 상태 변화 시뮬레이션을 만들어줘. 온도 슬라이더를 움직이면 물 입자의 움직임이 고체·액체·기체로 바뀌는 애니메이션과 현재 상태 이름이 보였으면 해. html로 만들어줘.
    중학교 사회 수업용으로 우리나라 인구 피라미드 비교 도구를 만들어줘. 1970년, 2000년, 2025년 버튼을 누르면 연령대별 막대그래프가 바뀌고, 각 시기의 특징을 한 줄로 설명해 줘. html로 만들어줘.
    중학교 1학년 영어 수업용 단어 카드 퀴즈를 만들어줘. 카드를 누르면 뒤집혀서 뜻이 나오고, 맞힘·틀림 버튼으로 점수가 쌓이며, 틀린 단어만 다시 풀 수 있었으면 좋겠어. html로 만들어줘.
  5. 마음에 안 드는 부분은 코드를 고치지 말고 말로 요청하세요. 화면을 캡처해서 붙여넣고 "여기 글자가 겹쳐"라고만 해도 됩니다.
  6. 완성되면 캔버스 오른쪽 위 공유 버튼으로 링크를 만들어, 실습실 실습①에 제출합니다.
💡 처음부터 완벽하게 쓰려고 하지 마세요. 짧게 요청해서 나온 걸 보고 두세 번 고치는 쪽이 더 빨라요.

🌱 초급 · 클로드로 수업용 시뮬레이션 만들기

준비물: claude.ai 계정 (구글 계정으로 가입 가능)약 30~40분결과물: 클로드 공유 링크

클로드는 따로 모드를 켜지 않아도 결과를 오른쪽 아티팩트 창에 미리보기로 보여 줘요. 말로 설명하고, 보고, 다듬는 흐름은 제미나이와 같습니다.

  1. claude.ai에 로그인합니다. 처음이면 Google로 계속하기로 바로 가입할 수 있어요.
  2. 새 대화를 열고 프롬프트를 입력합니다. 결과가 대화 속 코드로만 나오면 "아티팩트로 보여줘"라고 한 번 더 말하세요.
  3. 프롬프트에 아래 네 가지를 넣고, 마지막에 "하나의 html 파일로 만들어줘"를 붙입니다.
    ① 무엇을배울 개념
    ② 누구를대상 학년
    ③ 어떻게 조작슬라이더·버튼·입력
    ④ 무엇을 보여줄지그래프·애니메이션·숫자

    중학교 2학년 수학 수업용으로 일차함수 그래프 탐구 도구를 만들어줘. 기울기와 y절편을 슬라이더로 바꾸면 좌표평면 위의 직선이 바로 움직이고, 식 y = ax + b도 함께 바뀌어 보였으면 좋겠어. 하나의 html 파일로 만들어줘.
    중학교 1학년 과학 수업용으로 물의 상태 변화 시뮬레이션을 만들어줘. 온도 슬라이더를 움직이면 물 입자의 움직임이 고체·액체·기체로 바뀌는 애니메이션과 현재 상태 이름이 보였으면 해. 하나의 html 파일로 만들어줘.

  5. 고치고 싶은 점은 이어서 말로 요청하세요. 클로드는 같은 아티팩트를 고쳐 새 버전을 만들어 주고, 아티팩트 창에서 이전 버전으로 되돌아갈 수도 있어요.
  6. 완성되면 아티팩트 창 오른쪽 위 게시(Publish) 또는 공유 버튼으로 링크를 만들어, 실습실 실습①에 제출합니다.
💡 무료 계정은 하루에 보낼 수 있는 메시지 수가 정해져 있어요. 한 번 요청할 때 고칠 점을 두세 가지씩 묶어서 말하면 아낄 수 있어요.

🔌 중급 · 제미나이로 진짜 데이터 가져오기

준비물: 구글 계정약 30~40분결과물: 실시간 데이터를 보여 주는 앱

초급에서 만든 도구는 안에 넣어 둔 숫자만 보여 줬어요. 중급에서는 날씨, 미세먼지, 지진처럼 지금도 바뀌는 데이터를 다른 기관에서 받아 와 보여 줍니다. 이렇게 데이터를 주고받는 정해진 창구를 API라고 해요.

  1. 아래 예시 중 하나를 고릅니다. 오늘은 인증키 없이 바로 되는 API로 시작하는 걸 추천해요.
  2. 제미나이에서 Canvas를 켜고 예시 프롬프트를 붙여넣습니다.
    ✅ 인증키 없이 바로 작동
    Open-Meteo API(https://api.open-meteo.com/v1/forecast)를 fetch로 불러와서, 우리 학교 위치(위도 37.5, 경도 127.0)의 오늘 시간별 기온을 꺾은선 그래프로 보여주는 html을 만들어줘. 지금 기온은 크게 숫자로 보여주고, 인증키는 필요 없어. html로 만들어줘.
    Open-Meteo 대기질 API(https://air-quality-api.open-meteo.com/v1/air-quality)를 fetch로 불러와서, 위도 37.5, 경도 127.0의 지금 미세먼지(pm10)와 초미세먼지(pm2_5) 농도를 보여주는 html을 만들어줘. 좋음·보통·나쁨·매우나쁨을 색깔 카드로 표시하고, 인증키는 필요 없어. html로 만들어줘.
    USGS 지진 API(https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/4.5_week.geojson)를 fetch로 불러와서, 최근 일주일 동안 규모 4.5 이상 지진을 세계지도 위에 원으로 표시하는 html을 만들어줘. 원 크기는 규모에 비례하고, 누르면 장소와 시각이 나오게 해줘. 지도는 Leaflet을 CDN으로 불러와 써줘. html로 만들어줘.
    위키백과 요약 API(https://ko.wikipedia.org/api/rest_v1/page/summary/검색어)를 fetch로 불러와서, 낱말을 입력하면 한국어 위키백과의 첫 문단 요약과 대표 사진을 카드로 보여주는 html을 만들어줘. 예시로 '광합성'을 검색해 줘. html로 만들어줘.
  3. 내 아이디어로 바꿀 때는 이 틀을 채우면 됩니다.
    ✏️ 빈칸 채우기 틀
    [API 이름] API([API 주소])를 fetch로 불러와서 [보여줄 내용]을 [화면 모양]으로 보여주는 html을 만들어줘. 인증키는 [필요 없어 / 화면 입력칸에 넣게 해줘]. html로 만들어줘.
  4. 데이터가 안 뜨면 화면을 캡처해서 "데이터가 안 나와, 오류를 화면에 보여주게 고쳐줘"라고 요청하세요.
  5. 완성되면 공유 링크를 받아 실습실 실습③에 제출합니다. 쓴 API 이름도 함께 적어 주세요.
🔑 인증키를 써야 하는 API(공공데이터포털, 나이스 급식 등)는 키를 코드에 넣지 말고 "키는 화면 입력칸에 넣게 해줘"라고 요청하세요. 공유 링크를 받은 사람에게 내 키가 보이지 않아요.

준비물: claude.ai 계정 · 크롬 브라우저약 30~40분결과물: 실시간 데이터를 보여 주는 앱

날씨, 미세먼지, 지진처럼 지금도 바뀌는 데이터를 다른 기관에서 받아 와 보여 주는 앱을 만듭니다. 이렇게 데이터를 주고받는 정해진 창구를 API라고 해요.

⚠️ 먼저 알아 두세요. 클로드의 아티팩트 미리보기 창은 보안 때문에 바깥 사이트에서 데이터를 받아 오는 것을 막을 수 있어요. 미리보기에 데이터가 안 뜨면 앱이 잘못된 게 아니라, 아래 4번처럼 내려받아서 크롬으로 열어 확인하면 됩니다.
  1. 아래 예시 중 하나를 고릅니다. 오늘은 인증키 없이 바로 되는 API로 시작하는 걸 추천해요.

    Open-Meteo 대기질 API(https://air-quality-api.open-meteo.com/v1/air-quality)를 fetch로 불러와서, 위도 37.5, 경도 127.0의 지금 미세먼지(pm10)와 초미세먼지(pm2_5) 농도를 보여주는 앱을 만들어줘. 좋음·보통·나쁨·매우나쁨을 색깔 카드로 표시하고, 불러오기에 실패하면 이유를 화면에 보여줘. 하나의 html 파일로 만들어줘.

  3. 내 아이디어로 바꿀 때는 이 틀을 채우면 됩니다.
    ✏️ 빈칸 채우기 틀

  4. 미리보기에 데이터가 안 뜨면 아티팩트 창 오른쪽 위 다운로드로 .html 파일을 받아, 파일을 더블클릭해 크롬으로 열어 보세요. 그래도 안 되면 화면에 나온 오류를 캡처해서 클로드에게 보여 주세요.

💡 바깥 데이터를 쓰는 앱을 바로 공유하고 싶다면 이 단계는 제미나이 캔버스가 더 수월해요. 클로드는 화면 디자인과 긴 설명을 다듬는 데 강해서, 제미나이로 만든 앱 코드를 클로드에게 붙여넣고 "더 보기 좋게 다듬어줘"라고 하는 방법도 좋아요.
🔑 인증키가 필요한 API는 키를 코드에 넣지 말고 "키는 화면 입력칸에 넣게 해줘"라고 요청하세요.

아래 지침서를 복사해서 제미나이 새 대화에 붙여넣으세요. 그다음부터는 제미나이가 한 단계씩 물어보고 안내해 줘요. 시트 ID를 코드에 넣는 것처럼 헷갈리는 부분도 제미나이가 채워 줍니다.

지침서 펼치기
너는 구글 Apps Script로 웹앱을 처음 만드는 교사를 돕는 친절한 안내자야. 아래 순서를 지켜서 한 번에 한 단계씩만 안내해 줘. 내가 "됐어"라고 하면 다음 단계로 넘어가. 1. 먼저 무엇을 만들고 싶은지 물어봐. (누가 제출하는지, 어떤 항목을 받는지, 제출 뒤에 무엇을 보여줄지) 2. 빈 구글 스프레드시트를 만들고 그 주소를 붙여 달라고 해. 주소에서 스프레드시트 ID를 찾아서 코드에 직접 넣어 줘. 3. Code.gs 전체 코드를 한 번에 줘. doGet으로 화면(html 파일)을 보여주고, 제출하면 시트에 한 줄씩 저장되게 해. 첫 줄에는 항목 이름을 넣어 줘. 4. 화면 html 파일 이름을 정확히 알려주고, 그 파일의 전체 코드를 한 번에 줘. 휴대폰에서도 보기 좋게 만들어 줘. 5. [배포 → 새 배포 → 유형: 웹 앱 → 실행: 나 → 액세스 권한: 모든 사용자]로 배포하는 방법을 알려줘. 권한 승인 화면이 나오면 어떻게 넘어가는지도 알려줘. 6. 배포된 주소로 직접 제출해 보고 시트에 쌓였는지 확인하게 해. 7. 오류가 나면 내가 붙여넣는 오류 메시지를 보고 고친 코드 전체를 다시 줘. 코드는 항상 일부가 아니라 전체를 줘. 설명은 중학교 선생님이 이해할 수 있게 쉬운 말로 해 줘.

🎯 만들 것이 정해졌다면: 한 번에 요청하기

시트와 받을 항목이 이미 정해졌다면 이렇게 바로 요청해도 돼요. 대괄호 부분만 바꿔 쓰세요.

구글 스프레드시트([내 스프레드시트 주소])에 응답이 쌓이는 설문 웹앱을 Apps Script로 만들고 싶어. Code.gs와 화면 html 파일을 각각 전체 코드로 줘. 들어오면 이름을 입력하고 아래 질문에 답한 뒤 제출하면, 시트에 제출 시각과 함께 한 줄씩 저장되게 해줘. 1. (객관식) 오늘 연수 내용은 수업에 바로 쓸 수 있을 것 같나요? (바로 쓸 수 있어요 / 조금 다듬으면 쓸 수 있어요 / 아직 어려워요) 2. (주관식) 다음 연수에서 더 배우고 싶은 것을 적어 주세요. 제출이 끝나면 "제출했습니다" 화면을 보여줘. 휴대폰에서도 보기 좋게 만들어 줘.

전체 흐름 한눈에 보기

  1. 빈 구글 스프레드시트를 만들고 주소를 제미나이에게 알려 줍니다.
  2. 시트 메뉴 [확장 프로그램 → Apps Script]로 들어가서, 제미나이가 준 Code.gs 코드를 통째로 붙여넣고 저장합니다.
  3. 왼쪽 파일 목록의 ＋ → HTML로 새 파일을 만들고, 이름을 제미나이가 알려 준 것과 똑같이 짓고 화면 코드를 붙여넣습니다.
  4. 오른쪽 위 [배포 → 새 배포] → 유형 웹 앱 → 액세스 권한 모든 사용자로 배포합니다. 처음에는 권한 승인 화면이 나오니 내 계정을 골라 허용하세요.
  5. 배포 뒤 나온 웹 앱 URL로 들어가 직접 제출해 보고, 시트에 한 줄이 쌓였는지 확인합니다.
💡 코드를 고친 뒤에는 [배포 → 배포 관리 → 연필 아이콘 → 버전: 새 버전]으로 다시 배포하세요. "새 배포"를 또 누르면 주소가 바뀌어서, 이미 나눠 준 링크가 열리지 않아요.
